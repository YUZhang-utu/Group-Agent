# Macrocycle block-search publication direction

The proposed contribution is a measurable macrocycle-specific cost/recall advantage across independent targets, followed by prospective hit validation. Generic block prescreening already has close precedents, including AdaptiveFlow (Nature Biotechnology, September 2026).

Start with a tractable common reference library and a frozen MDM2 development protocol. Compare unpartitioned 3D search, random allocation, property tranches, E094/E095/E096 and active learning under matched total budgets. Keep pilot molecules separate from evaluation molecules and count all conformers of one molecule together in splits. The three current receptor states are one target. Computational score recovery is not experimental enrichment.

[Full proposed protocol](../experiments/E105-macrocycle-block-search-benchmark.md) defines target selection, cost accounting, metrics, ablations and assay controls. No new benchmark or remote campaign was launched in preparing this document. Current search execution still requires a fresh workstation status receipt.
