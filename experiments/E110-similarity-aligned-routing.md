# E110: similarity-aligned block priority

Hypothesis: blocks with more qualifying molecules among 500 uniformly sampled distinct molecules yield more unseen qualifying molecules per evaluated conformer than random block order, using exactly the frozen E109 threshold query and evaluator.

Default scope is E094 only to bound fitting cost. E095/E096 are explicit optional schemes. Each selected scheme draws exactly 500 distinct eligible molecules per block without replacement using a seeded SHA256 order. All eligible conformers of the union of sampled molecules are evaluated once; only in-block conformers determine that block's positive count. A molecule qualifies if any of its in-block conformers passes any query template (stage 7). Rank by positive count descending, tie by block identifier. This is a threshold-yield endpoint, not global RRF Top-K or activity enrichment.

Reuse sealed E109 pilot evaluations including negative outcomes. Compute only missing fitting conformers. Use the original pilot's remaining molecules as a bounded validation population, globally excluding every sampled molecule across all selected schemes. Freeze priorities using fit outcomes only. This follow-up is exploratory because the pilot's previous aggregate results motivated it; a later disjoint validation is required for confirmation.

Primary metrics: distinct qualifying molecules at fixed 10%, 20%, 50% validation conformer budgets; conformer work needed for fixed targets of 1000, 10000 and 50000 qualifying molecules. Report failures to reach targets explicitly. Compare similarity priority, existing ChemPLP/EquiScore priorities and 20 seeded random block orders on identical held-out populations. Count only complete blocks at fixed budgets, deduplicate molecules across blocks, and distinguish zero-validation blocks from missing priorities.

Report fitting conformers (logical total, reused, newly evaluated), fitting wall time and complete-block discovery curves. Charge logical fitting work to the similarity strategy when reporting cold total conformer work; cache reuse is operational savings only. Cold pilot replay is not a full-library speed estimate and may be dominated by fitting costs. Do not convert work reduction into measured wall-time speedup. No full-library reference, docking or 21-run timing campaign is automatically launched.

Keep the scientific modules unchanged so existing E109 prepared code identities remain valid. Use synthetic tests for leakage, negative-cache reuse, molecule/conformer counting, ties, budgets, failure paths and resume.
