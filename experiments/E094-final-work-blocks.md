# E094: size-controlled work blocks and continuous side-chain refinement

## Question and hypothesis
Can the admitted library be organized without tiny execution blocks while preserving every original identity and E091 routing decision? Can continuous side-chain chemistry and steric summaries refine large work blocks without introducing small leaves?

## Protocol before execution
1. Verify immutable model, diagnostic, candidate and routing receipts and database hashes. Audit the complete E091 sidecar against source CIDs, original groups, candidate targets/rotations and calibrated acceptance evidence. Preserve the 1,150,072 separate chemistry-review records outside scope.
2. Count final definite and provisional target classes. Use a default minimum work-block population of 5,000, no maximum capacity. Large classes remain alone. Pool small classes by length and directed cis/trans pattern; attach residual small pools to existing work blocks, preferring matching pattern then length. Record all mixed execution pools. This is scheduling, not chemical equivalence. Keep one exhaustive special pool.
3. Write a compact overlay and class-to-work-block map; enumerate memberships through the original indexed store. Check population conservation, sidecar uniqueness and no regular block below the minimum (except a library whose entire regular population is smaller).
4. Prepare continuous property summaries, reusing verified E091 features. Missing ordinary profiles require source-verified extraction. Extraction can resume only with unchanged inputs/code and committed profiles. Full coverage is required before property splitting; sparse evidence never labels all members.
5. Within each regular work block, allow at most eight adaptive property leaves. Split only when both children have at least 5,000 conformers and normalized centroid contrast meets the configured threshold. Report the threshold as exploratory, not biological-state separation. Special records remain exhaustive.
6. Tests must cover rare-pattern tails, chirality identity retention, malformed routing, hash changes, source conservation, property coverage gaps, tie-heavy distributions and population floors. Run a real small-source replay. No held-out search recall or vendor docking claim.

## Metrics
Regular and special populations; number and histogram of work blocks; small-block count; mixed-pattern/length execution pools; property profile coverage; split contrasts; output hashes; input preservation; stage wall time.

## Scope
This stage completes an offline enumerable work-block artifact, not production search dispatch, source-to-registry joining, activity screening, PLANTS or N-E execution. Original radii cannot bound expanded memberships. Workstation wall time and scientific recall remain to be measured.
