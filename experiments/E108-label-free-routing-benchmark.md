# E108: label-free routing benchmark

Protocol recorded before implementation and fixture validation, 2026-10-14.
The existing twelve arm counts have already been inspected. Historical comparisons
are retrospective, not confirmatory. No activity labels exist for this library.

## Hypothesis and endpoints

At matched work, prioritized structural blocks recover more independently frozen
reference candidates than random block ordering. At matched recovery and output
budget, the deployed pipeline may use less wall time than the specified baseline.
Neither hypothesis is assumed true. Reference agreement is not biological activity.

1. Reuse the historical ANN-derived million-conformer export. Verify sealed tables,
   contiguous ranks and source identity. Join current artifact_cid to historical
   conformer_id through the read-only registry, not structural cid or ligand names.
   Validate source hashes and canonical molecule identity. Compare all twelve arms
   on conformer and first-occurrence molecule reference ranks at multiple K values.
   Preserve shortfalls; report fixed export-prefix sensitivity and Top5/Top10 gains.
   These ranks differ from current threshold-funnel ranks: this is historical
   reference recovery, not exhaustive same-policy recall. New candidates are unknown,
   not false positives. No automatic speedup from existing cached timings.
2. For a stronger routing-only experiment, freeze a complete evaluated universe
   (full regular library or a molecule-sampled sublibrary), including rejected rows,
   with all three partition memberships and a common qualified reference ranking.
   Freeze independently generated block priorities, excluding priority-fit molecules
   from evaluation. Replay block order and repeated random orders, finishing whole
   blocks. Evaluate prefix work/recovery and work needed for 90% reference recovery.
   Uniform-conformer random ordering is a separate baseline. No replay wall times
   are search runtime. This measures discovery before final output truncation, not
   the deployed RRF top-100000 export. Special pools are excluded explicitly.
3. Measure real end-to-end commands in fresh output locations. Freeze baseline,
   library/query/eligibility/ranking/budget, hardware/workers and cache policy in a
   shared comparison specification. Alternate methods over at least three repeats.
   Record setup and online phases separately; do not flush OS caches automatically.
   Verify achieved recall and output budget using analysis before interpreting time
   ratios. Record failures and source receipts. Historical ANN and current threshold
   runs are different policies and cannot establish an isolated routing speedup.

## Outputs and decisions

Machine-readable provenance, historical recovery tables, exact pairwise overlap,
paired limit gains, reference-recovery versus searched-work plots, replay curves,
random-repeat summaries, and raw measured timing receipts. Avoid a composite winner.
Prefer Pareto-efficient policies at a predeclared application budget. Include
partition construction, initial block sampling/scoring and amortized repeated-query
costs; a finer partition does not receive free extra priority-training work.

Historical result tables alone cannot establish complete-library recall. A complete
universe and valid cold measurements are optional inputs, not fabricated defaults.
The tools must mark missing stages and never launch expensive search from analysis.
Validate malformed/duplicate identities, hashes, namespaces, ranks, shortfalls,
cache timing exclusions, replay controls, deterministic seeds and incomplete runs.
