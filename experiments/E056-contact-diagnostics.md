# E056 contact evidence and matching diagnostics

Protocol recorded before execution. Confirmatory tests cover identity matching,
known angular perturbations, source-instance atom identity, missing mappings,
pairwise duplicate relationships without transitive merging, and optional-family
assignment against exhaustive small cases. Preserve production matching and
scientific weights; expose an alternative optional-only assignment as a diagnostic,
not an automatic replacement for hard-rule or multi-contact matching.

Run three diagnostics: feature identity, source-observation recovery, and crystal
against consensus. Report unmatched rows, spatial and angular factors, direction
kind, feature type and weighted score contributions. Identity errors are software
failures, whereas consensus mismatch does not establish biological inactivity.

Run regression tests and a sealed local real-structure audit. New metadata must
not change evidence IDs. Recover old source indices only from verified query
manifests, otherwise mark unavailable. No active/decoy test or full-library run.
