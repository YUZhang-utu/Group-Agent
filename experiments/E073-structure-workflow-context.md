# E073: structure workflow navigation

Hypothesis: exposing actual stage/source relationships and reference evidence to
the existing domain loop reduces selection of unrelated tasks and confusion between
budgeted retrieval and threshold screening, without changing scientific algorithms.

Protocol: construct owned diversity/consensus/recommendation/budget task fixtures;
inspect source relationships and similarity artifacts; verify unresolved reference
and failed child reports offer no transition; verify session and path isolation.
Run the domain and Chat regression suites. No heavy or external scientific run.

Acceptance: the intended branch retains its source IDs; real matrix values are
readable; another session has no tasks; no navigation call dispatches computation.
Scientific ranking equivalence is outside scope because ranking code is unchanged.

Confirmatory local result: 21 focused tests passed, including three new workflow
navigation tests. Model routing quality and end-to-end workstation behavior remain
exploratory live acceptance items, not established by these fixtures.
